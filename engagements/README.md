# Engagement Snapshots

Live page: https://vacobyhighspring.github.io/solutions/engagements/

## Sharing one snapshot
- **Link:** open a snapshot and tap **Copy link**. Links look like `.../engagements/#case-29`.
- **Standalone file:** tap **Download HTML**. You get a single file showing only that snapshot, which you can email or upload anywhere.

## What it is
One searchable library of every technology and digital snapshot: our Northeast team's snapshots, plus all technology snapshots from vaco.com and highspring.com (94 total as of Nov 2026). Filter by Service (Consulting, Managed Services, Staff Augmentation, Executive Search, Direct Hire), Area of Expertise, Industry, Source and Location.

Case studies from the websites keep a link to the original page, and every snapshot can be downloaded as its own HTML page.

## Adding a snapshot
Send Claude the details (a PDF, a slide, a link or plain notes). It needs: title, client description (no client name unless it's already public), industry, services, challenge, solution, impact, and any numbers. Claude adds it to the `CASES` list in `index.html`, tests it and publishes it.

## Monthly refresh
A scheduled task checks the vaco.com and highspring.com snapshot libraries each month. Any new technology snapshot is added and published.

## Naming
Called "Engagement Snapshots", not case studies: representative summaries with client names withheld, not client references. A disclaimer appears in the footer of every page and download.
